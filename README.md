# AML Training Lab

An interactive training app for anti-money laundering (AML) and transaction monitoring.

**Open the app:** https://justinspratt07.github.io/aml-training-lab/

## What's inside

- **Learn** – eight modules covering how laundering works, the US legal framework, KYC, sanctions and screening, monitoring systems, typologies, investigations and analyst tools.
- **Rules lab** – tune seven monitoring scenarios over a fictional customer base and see the effect on alerts, false positives and missed cases.
- **Cases** – work practice alerts with full customer files and answer multiple-choice assessment questions.
- **Assessments** – module checks and a 50-question final assessment (80% pass mark).
- **Reference** – glossary and official sources (FFIEC, FinCEN, OFAC, FATF).

All customers, accounts and jurisdictions in the app are fictional. Progress is saved in each user's browser.

The app is a single self-contained `index.html` file and can also be opened directly in any browser.
